# video-board

Видео-доска: список ников с раскрывающимися плашками видео, поиск, предложения от посетителей, мини-чат, комментарии, админ-панель.

Стек: Node.js 20+ / Express, хранение — JSON-файл в `data/` (без нативных зависимостей, чтобы `npm install` проходил на любом хостинге).

## Запуск

```
npm install
npm start          # PORT берётся из окружения, по умолчанию 3000
```

## Переменные окружения

Читаются из настоящего окружения, а то, что не задано, добирается из файла `.env`
в корне проекта (шаблон — `.env.example`, сам `.env` в git не попадает). Это удобно на
хостинге, где панель не даёт открыть вкладку с переменными: файл правится через
Files/SFTP и применяется перезапуском.

| Переменная      | Назначение                                                        | По умолчанию        |
| --------------- | ----------------------------------------------------------------- | ------------------- |
| `PORT`          | порт HTTP-сервера, если задала его платформа                       | —                   |
| `SERVER_PORT`   | порт, выданный Botkeep (Overview → Port), когда `PORT` не проброшен  | `34086`             |
| `ADMIN_NICK`    | ник администратора, создаётся при первом старте                    | `admin`             |
| `ADMIN_PASSWORD`| пароль администратора; без него генерируется случайный и пишется в лог | —                   |
| `SESSION_SECRET`| ключ подписи сессий (обязателен в проде)                           | —                   |
| `BASE_PATH`     | префикс, если сайт живёт в подпапке (например `/app/video-board`)  | `""`                |
| `DATA_DIR`      | папка для `db.json`                                                | `./data`            |

## Структура

```
server.js          входная точка
src/db.js          хранилище (атомарная запись db.json)
src/events.js      SSE-хаб для чата и обновлений
src/auth.js        сессии, пароли (scrypt), проверка прав
src/video.js       превращает ссылку в iframe/<video> (YouTube, Twitch, Vimeo, Rutube, OK, прямые файлы)
src/api.js         все JSON-эндпоинты, в т.ч. /api/admin/*
src/pages.js       HTML-страницы
public/            стили и клиентский JS
```
